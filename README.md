# 125A Drumator

Vintage-inspired multi-format drum sampler with a 32-step running-light sequencer. Focus: **drop a sample onto a drum row, program steps, play.**

**Status:** development; Windows standalone C++ sequencer and sample-voice test suites 2/2 PASS. **NO playable VST3 binary or release yet.**
